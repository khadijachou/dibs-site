Vos NIM restent à vous

Dibs ajoute des objectifs à votre propre portefeuille. Il ne détient jamais vos NIM ni les clés. Vous approuvez chaque étape dans Nimiq Pay.

Dibs peut

  • Afficher votre objectif et votre progression
  • Préparer chaque étape que vous approuvez dans Nimiq Pay
  • Vérifier le prix et la disponibilité avant l’achat
  • Afficher votre code de carte-cadeau sur votre téléphone, dans l’application

Dibs ne peut pas

  • Déplacer vos NIM sans votre accord
  • Détenir vos NIM ou une clé de votre portefeuille
  • Payer deux fois la même carte
  • Lire les codes de cadeau chiffrés de bout en bout transmis par le serveur Amis

Comment nous assurons cette protection

Voir le code sur GitHub

  • En staking à votre propre adresse

    Vos NIM sont mis en staking à votre adresse, dans le pool choisi parmi cinq options vérifiées. Garuda Pool est présélectionné. Les récompenses ne sont pas garanties. Le déblocage prend de 12 à 24 heures.

  • Aucune inscription

    Aucun compte, courriel ni mot de passe. Vos objectifs et votre nom restent sur votre téléphone.

  • Statistiques uniquement avec votre accord

    Les chiffres d’utilisation anonymes ne sont partagés que si vous touchez « Partager les stats », sans nom, code ni adresse. Vous pouvez désactiver ce partage ou supprimer les données partagées.

  • Aucune opération financière relancée à votre place

    Chaque avis explique ce qui s’est passé, si vos NIM ont bougé et quoi faire ensuite. Annuler dans Nimiq Pay est une issue normale.

  • Code source ouvert

    Le code de l’application est public sous licence MIT. Tout le monde peut examiner ce que fait Dibs à chaque étape.

Les amis, c’est votre choix

Amis est désactivé jusqu’à ce que vous l’activiez. Vos objectifs d’épargne restent sur votre téléphone et vous contrôlez ce que vos amis voient.

Qui voit quoi

Sept réglages distincts permettent de ne rien partager, de partager avec les amis ou avec tout le monde. Les détails partagés restent sur le serveur Amis seulement tant que vous choisissez de les afficher.

Codes de cadeau privés

Les codes envoyés dans Dibs sont verrouillés sur votre téléphone pour celui de votre ami. Le serveur ne peut pas les lire. Ils sont supprimés à l’ouverture ou après 30 jours.

Classements facultatifs

Participez au classement des amis ou général seulement si vous le souhaitez. Les dépôts sont vérifiés sur la chaîne sans conserver leur identifiant de transaction ni votre adresse de portefeuille.

Vos données à supprimer

Le serveur Amis conserve le nom affiché et les renseignements nécessaires aux cadeaux facultatifs, dont le message, la bannière et la valeur de la carte, visibles par le destinataire. Supprimez vos données Amis sous Profil > Amis > Vous.

Cartes-cadeaux fournies par Bitrefill

Toutes les marques et cartes Dibs proviennent de Bitrefill, une boutique de cartes-cadeaux acceptant Lightning. Votre objectif atteint, Dibs achète la carte au prix de Bitrefill, payé en NIM par Lightning dans Nimiq Pay.

Dibs est indépendant. Il n’est ni commandité par Bitrefill ou les marques présentées, ni leur partenaire ni approuvé par eux.

Vérifier sur la chaîne

Les liens ouvrent nimiq.watch, un explorateur de la chaîne Nimiq. D’autres achats sont ajoutés lorsque leurs acheteurs acceptent de les partager.
